# מנגינה במסלול – אבטיפוס

משחק פלטפורמה דו־ממדי לילדים: הדמות רצה לבד, והילד שר או מזמזם כדי להעביר אותה במסלול. ציר ה-X הוא התזמון של השיר, וציר ה-Y הוא גובה התו.

שלב מלא אחד: „יונתן הקטן”. שלושת השירים האחרים מופיעים במסך הבחירה כ„בקרוב”.

## הרצה

אין התקנות ואין שלב בנייה.

```
cd melody-path
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: http://localhost:8000

מיקרופון עובד רק מ-`localhost` או מ-HTTPS. פתיחה ישירה של `index.html` (לחיצה כפולה) מספיקה למצב ההדגמה.

## איך משחקים

1. בוחרים „יונתן הקטן”.
2. במסך ההתאמה אפשר לזמזם צליל נוח (המשחק בוחר סולם), להעלות או להוריד ידנית, להשמיע דוגמה, או להתחיל מיד.
3. כל משפט: שומעים אותו בקסילופון והמסלול מודגש ← צליל הפתיחה שוב ← ספירה 1, 2 ← שרים.
4. העיגול הקטן ליד המשטח הבא מראה את גובה הקול. כתום עם חץ: להתקרב למעלה או למטה. ירוק: זה התו.
5. פספוס: יונתן מחכה. „שמע שוב” או „נסה שוב” ממשיכים מאותה נקודה.

מצב הדגמה (בלי מיקרופון): מקשי `1`–`5` הם דו–סול, `רווח` הוא תמיד התו הנכון, `Enter` לניסיון נוסף, `H` לשמוע שוב. במסך מגע יש כפתורים.

## מבנה

```
index.html
css/style.css
js/songs/registry.js    רישום שירים
js/songs/yonatan.js     נתוני השלב: תווים, משפטים, סצנות, תפאורה
js/songs/upcoming.js    שלושת השלבים העתידיים (כותרת ותיאור בלבד)
js/engine/run.js        לוגיקת המשחק (בלי DOM)
js/engine/pitch.js      מיקרופון וזיהוי גובה קול (YIN), מקומי בלבד
js/engine/audio.js      קסילופון, פעמה, אפקטים, קלט מצב הדגמה
js/engine/render.js     ציור: סגנונות משטח, תפאורה, דמות
js/main.js              ממשק ומסכים
tests/                  בדיקות
```

### הוספת שלב

יוצרים קובץ ב-`js/songs/` באותו מבנה כמו `yonatan.js` (או משלימים רשומה ב-`upcoming.js` ומשנים `available: true`):
`bpm`, `defaultTonic`, `start`, ו-`phrases` שבהם כל תו הוא `{ p: חצאי טונים מעל הטוניקה, d: אורך בפעמות }`, עם `style`, `crawl`, `prop`, `flag`, `fx` לפי הצורך. המנוע מחשב לבד קפיצה, ריצה על אותו גובה או ירידה.
סגנונות חדשים (מדרגות מגדל, גלים, גשרים, עננים) נרשמים ב-`SG.Render.platformStyles`, `crawls`, `props`, `backdrops`, `finales`.

### כיוונון

ב-`js/engine/run.js`, `SG.defaults`: מרווח הגובה (`toleranceSemis`, ברירת מחדל 1.5 חצאי טון, בכל אוקטבה), זמן הצליל היציב (`holdSec`, 0.11 שניות), הקדמה ואיחור מותרים (`earlyBeats`, `lateBeats`). אפשר לדרוס לכל שיר בשדה `tuning`.

## בדיקות

```
node tests/logic.test.js     לוגיקה וזיהוי גובה על אות סינתטי, בלי דפדפן
node tests/e2e.mjs           דפדפן אמיתי (Playwright + Chrome), עם מיקרופון וירטואלי
```

המיקרופון בבדיקות הדפדפן הוא אוסילטור שמוזן ל-`getUserMedia`. האבטיפוס עדיין לא נבדק עם מיקרופון פיזי ועם קול של ילד.
